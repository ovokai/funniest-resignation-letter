A cron job that has fired every minute since March finally files its resignation the only way it knows how: with a passive-aggressive note about last email. The entry: *Per my last email, I've fired every minute since March. Still no thank you. Per this minute: I quit. - Your Cron Job*

## Run it

```sh
node main.ts
```
